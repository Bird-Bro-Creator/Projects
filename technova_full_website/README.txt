# TechNova Full Website

This is a complete frontend website built with:

- HTML
- CSS
- JavaScript

## Features

- Responsive navigation
- Dark mode with localStorage
- Hero section
- About section
- Services section
- Searchable and filterable project section
- Project modal popup
- Pricing cards
- Testimonials slider
- FAQ accordion
- Contact form validation
- Toast messages
- Back-to-top button
- Scroll reveal animations

## Files

- `index.html` - Website structure
- `style.css` - Website design and responsiveness
- `script.js` - Website interactivity

## Note

This is a frontend-only website. It does not save contact form messages to a database.
To make the contact form really send messages, connect it to a backend service such as:
Firebase, Supabase, Node.js, PHP, or Formspree.
